# Artwork

Logos printed on the boards, as SVG for reuse (1 SVG unit = 1 mm, the size
used on the motor board). Monochrome: **black = ink**. On a PCB the ink is
the silkscreen (white), so in the flag the solid area is the white field.

| File | Contents |
|---|---|
| `emblem_small.svg` | Volcano emblem (Lonquimay, Llaima, Villarrica, Osorno, from real elevation data) with the "ANDES MADE" title, 21 mm wide |
| `emblem_small_notext.svg` | The same, frame and picture only |
| `flag.svg` | Flag of Chile with heraldic hatching (blue = horizontal, red = vertical) and "Designed in Chile by Gonz", 7.2 mm wide |
| `flag_plain.svg` | The same without the hatching lines |

Generated by `../motor-pcb/tools/export_svg.py` from `emblem_small.json`
(made by `emblem_small.py`) and the flag code in `../motor-pcb/tools/artwork.py`,
which also draws them on the board. Edit the scripts, not the SVGs.
The flag text is a plain SVG `<text>` (DejaVu Sans / Arial), not outlines.
